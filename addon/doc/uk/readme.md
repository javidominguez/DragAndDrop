# DragAndDrop (Перетягування)

Додаток для NVDA, який дає змогу перетягувати об’єкти.

## ВИКОРИСТАННЯ

1. Виберіть об’єкт, який хочете перетягнути.
2. Перемістіть курсор мишки чи об’єкт навігатора до місця, в яке ви хочете його помістити.
3. Оберіть параметр для переміщення.

| назва скрипта | Desktop-розкладка | Laptop-розкладка | Опис |
| - | - | - | - |
| Інформація про курсор миші | NVDA+- | NVDA+Control+, | Повідомляє позицію курсора миші і об’єкт, на який він вказує. Подвійне натискання повідомляє назву об’єкта, вибраного для перетягування. |
| Вибрати об'єкт для перетягування | NVDA+, | NVDA+, | Позначає об’єкт у позиції навігатора для перетягування. |
| Перетягнути та помістити | NVDA+. | NVDA+Shift+, | Перетягує вибраний об’єкт. Потім натисніть пробіл, стрілки чи Enter, щоб обрати, куди його помістити. |


Доступні такі параметри перетягування:

- Натисніть Enter для перетягування вибраного об’єкта в поточну позицію курсора миші.
- Натисніть пробіл для перетягування його до поточного об’єкта в позиції навігатора.
- Натисніть стрілки для перетягування його у межах поточного об’єкта в позиції навігатора.
